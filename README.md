# Logo. Ecommerce

Criei o projeto Logo como o intuito de expandir minhas habilidades em desenvolvimento web. O processo foi necessário para fincar conhecimentos sobre HTML e CSS.<br>Na Logo, acreditamos que o luxo reside na simplicidade. Nossa curadoria oferece produtos refinados com uma experiência de compra ágil: tudo o que você precisa, a um clique de distância. Logo exigiu horas quebrando a cabeça para superar obstáculos de design e otimização de código que surgem no dia a dia da área.
